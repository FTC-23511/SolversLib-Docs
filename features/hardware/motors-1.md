# Deprecated Hardware

SolversLib used to offers much simpler motor wrappers for motor caching & easy usage of [Axon Servos](https://axon-robotics.com/collections/servos). However, it is now deprecated, as these features have been merged into FTCLib's [native hardware classes](./), which has been rewritten to better support it.
